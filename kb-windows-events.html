NOTE 17 / Cloud & telemetry

Windows logons: correlate the session_

Study basis: Lab application

THE PRINCIPLE

An event ID identifies an event type; account, logon context, and related records determine its investigative meaning.

THE CONNECTION

Event 4672 initially looked like a privilege-escalation verdict. It actually records special privileges assigned to a new logon and needs context.

Read the event without overclaiming

EventRecordsDoes not prove by itself
4624A successful logonThe activity was authorized by the account owner
4625A failed logonAn attacker caused the failure
4672Special privileges assigned to a new logonA successful privilege-escalation exploit

Understand the privileged-logon question

Administrative and system activity can legitimately generate 4672. Its significance depends on which account received privileges, on which host, at what time, and in which session. A SYSTEM account label is not a blanket guarantee that all surrounding activity is harmless.

Correlate the logon identifier with related records on the same computer, taking timestamps and system restarts into account. A logon ID is not a universal identifier for one session across every host.

Inspect fields that explain the attempt

For a logon event, inspect the relevant account, computer, logon type, authentication information, source details where populated, and time. Failed logons include status information that can help distinguish causes. Field availability depends on the logon context and authentication path.

A missing source address does not establish that an event is benign or malicious. It can reflect the event's context. Likewise, a successful logon after failures is a lead: establish whether the records actually concern the same account, origin, and activity.

Write the conclusion at the evidence level

“A privileged logon occurred for this account on this host” is supported by the event. “The host was exploited” requires additional evidence. The distinction keeps alert triage useful and prevents an event label from becoming an unsupported incident verdict.

CLOSE THE NOTES. MAKE THE CONNECTION.

Recall check

Does event 4672 alone confirm privilege escalation?

Reveal the reasoning

No. It records special privileges assigned to a new logon. Correlate the account, host, session, and surrounding activity to decide whether that privileged logon was expected.
