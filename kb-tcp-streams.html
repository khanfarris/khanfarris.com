NOTE 20 / Networking

Wireshark: identify the conversation_

Study basis: Concept study

THE PRINCIPLE

A packet's stream label, sequence number, and header offset describe different coordinates.

THE CONNECTION

A TCP stream index groups a connection in the capture. It is not the packet's position in that connection, and a browser tab is not a reliable one-to-one connection identifier.

Separate stream and sequence

Wireshark's tcp.stream field is an analysis index used to group packets belonging to a TCP conversation in that capture. It is not transmitted as a TCP header field. TCP sequence numbers track positions in the byte stream; they are not Wireshark's conversation number. SYN and FIN also consume sequence-number space.

A filter such as tcp.stream == 3 selects a conversation identified by the analyzer. It does not request the third packet or byte. Stream indices should not be assumed to match across separately processed captures.

Use the endpoints

Source and destination addresses and ports distinguish the endpoints of a TCP connection. A client commonly selects an ephemeral source port while connecting to a service's destination port. The reply reverses those roles. A changing client port is not, by itself, an indication of malicious behavior.

A browser tab may open multiple connections. Multiple requests can also share a connection; HTTP/2 supports multiplexing. Counting tabs therefore does not reliably predict the number of TCP streams.

Read offsets and padding in their own units

A hexadecimal offset locates a byte in the displayed data: 0x16 is decimal 22 and 0x80 is decimal 128. An offset is not a sequence number or an address on the network.

The TCP Data Offset describes the TCP header length in 32-bit words. Options and any necessary padding keep the header on that four-byte boundary. The packing-material analogy explains alignment, but padding is still defined header structure rather than application payload.

Keep the conclusion narrow

First identify the conversation, then inspect its ordered evidence and the protocol being carried. Header structure can explain where bytes belong. It cannot alone establish whether the application action was authorized or malicious.

CLOSE THE NOTES. MAKE THE CONNECTION.

Recall check

Does tcp.stream == 4 mean the fourth packet from the fourth browser tab?

Reveal the reasoning

No. It selects Wireshark's TCP conversation index 4 in that capture. Packet order, sequence numbers, and browser tabs are separate concepts.
