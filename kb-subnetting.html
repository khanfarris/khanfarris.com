NOTE 02 / Networking

IPv4 subnet boundaries_

Study basis: Practiced calculations

THE PRINCIPLE

Separate total address count from the increment in the changing octet. Derive every boundary from the network address.

THE CONNECTION

A /29 contains eight total addresses. A /21 contains 2,048 total addresses but advances by eight in the third octet. Those numbers describe different things.

Bits, values, and host capacity

An IPv4 address contains 32 bits. A /28 prefix reserves 28 network bits and leaves four host bits. A subnet mask has ones in the network positions and zeros in the host positions. An octet contains eight bits and 256 possible values, numbered 0 through 255. Zero is a number, not “null”; an octet does not contain 256 bits.

Host bits = 32 − prefix
Total addresses = 2host bits
Ordinary IPv4 subnet host capacity = total addresses − 2

The subtraction reserves the all-zero host value for the network and the all-one host value for broadcast. It works regardless of the octet boundary for ordinary IPv4 broadcast subnets. It is not universal: /31 point-to-point links can use both addresses, while /32 denotes one address. Cloud-platform reservations can further reduce assignable capacity.

Worked example: 192.168.204.30/28

  1. Host bits: 32 − 28 = 4. Total addresses: 16. Ordinary usable capacity: 14.
  2. Mask: 11111111.11111111.11111111.11110000 = 255.255.255.240.
  3. Fourth-octet increment: 256 − 240 = 16.
  4. The greatest multiple of 16 not exceeding 30 is 16. Network: 192.168.204.16.
  5. The next block starts at .32. Broadcast is one address earlier: 192.168.204.31.
  6. Usable range: 192.168.204.17–192.168.204.30.

When the mask changes in the third octet

For 10.50.132.75/21, 11 host bits give 2,048 total addresses and 2,046 ordinary usable addresses. The mask is 255.255.248.0. The third-octet increment is 256 − 248 = 8, not 2,048.

The block containing 132 begins at 128 and ends at 135. Network: 10.50.128.0. Broadcast: 10.50.135.255. Host range: 10.50.128.1–10.50.135.254. All host bits are zero at the network boundary and one at the broadcast boundary, explaining the last octet's 0 and 255.

Checks that prevent repeat errors

  • The increment is 256 − mask octet in the partially masked octet. There are 256 possible octet values, although 255 is the largest.
  • Calculate broadcast from the network boundary, not the original host octet: 128 + 8 − 1 = 135.
  • For 10.0.0.150/28, network .144 has broadcast .159. Address .160 starts the next subnet.
  • A /26 has six host bits. The prefix is 26, not six.
CLOSE THE NOTES. MAKE THE CONNECTION.

Recall check

For 172.19.155.200/18, find the mask, network, broadcast, and ordinary usable capacity.

Reveal the reasoning

Mask 255.255.192.0; increment 64 in the third octet; network 172.19.128.0; broadcast 172.19.191.255; usable range 172.19.128.1–172.19.191.254; capacity 16,382. The next network begins at 172.19.192.0.
