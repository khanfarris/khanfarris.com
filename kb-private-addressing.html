NOTE 01 / Networking

Private IPv4 & NAT_

Concept Concept study

IN PLAIN ENGLISH

A private IP identifies a device inside a network. NAT lets devices using private addresses communicate through an internet-facing address.

Start with the address

An IPv4 address is four numbers separated by dots, such as 10.0.0.25. Each number can be 0–255. Your laptop needs an address so other devices can send traffic to it. A private address can be reused inside different homes and businesses because it is not routed directly across the public internet.

Private rangeExample
10.0.0.0–10.255.255.25510.0.0.25
172.16.0.0–172.31.255.255172.20.5.10
192.168.0.0–192.168.255.255192.168.1.20

A 10.x address is just as private as a 192.168.x address. The administrator or router configuration chooses which range to use. Only 172.16 through 172.31 is private in the 172 range. Also notice the spelling: 196.168 is different from 192.168. Addresses outside these ranges are not automatically public; other special ranges exist.

What NAT actually changes

Network Address Translation (NAT) changes addresses as traffic passes through a router or firewall. In a typical office, the device changes a laptop’s private source address into the address used on the internet side. Port Address Translation (PAT) also tracks port numbers, allowing many laptops to share one public address. A port identifies a particular service or connection on a device.

Laptop                  Office gateway              Website
10.0.0.25:53010    →     203.0.113.10:62001     →     TCP 443
                        Translation recorded
Reply to :62001   →     matches the record     →     laptop :53010

The gateway keeps a translation table so replies return to the right laptop. The public address above is reserved for documentation. Real connections can also pass through another translation at the internet provider.

Different networks can share an internet connection

An office might put staff in 10.10.10.0/24 and guests in 192.168.20.0/24. Both can use the same public internet address. Creating another VLAN or subnet does not automatically create or require another public IP. Internal separation and internet address translation are separate settings.

Use it on a support or security ticket

If a user reports “my IP is 10.x instead of 192.168.x,” that alone is not a fault. Compare their address, subnet mask, gateway, and DNS servers with the intended network using ipconfig /all. When investigating an external service’s logs, its recorded source may be the office’s public address. Use the timestamp and translation or connection records to identify an internal device; do not assume that public address identifies one employee.

Remember

NAT changes addresses. Firewall rules decide which traffic is allowed. A malicious program can still make outbound connections through NAT.

PUT IT INTO WORDS

Check your understanding

Do a staff VLAN and a guest VLAN need separate public IP addresses?

Show an example answer

No. They can use different private subnets and share a public address through PAT. Their separation depends on VLAN configuration and the rules controlling traffic between them, not on having different public IPs.
