NOTE 14 / Identity & access

File shares: a path is not permission_

Study basis: Concept study

THE PRINCIPLE

A mapped drive is a convenient reference to a resource, not the server or the access control protecting it.

THE CONNECTION

A drive letter, a file-server role, a NAS appliance, and the host running that service describe different parts of the same access path.

Resolve the names

A mapped drive such as Z: points to a network location. A UNC path such as \\fileserver\team identifies a server name and share. The drive letter is a local convenience: removing the mapping does not delete the server's data.

A file server is a service role. It can run on a physical server, a virtual machine, or an appliance. A Network Attached Storage device commonly provides file access over the network, but its additional capabilities depend on the product. “Virtual” and “file server” are not mutually exclusive descriptions.

Follow a failed access request

  1. Identify the actual UNC target behind the drive letter.
  2. Check whether the server name resolves as expected.
  3. Check the permitted network path and whether the file service is available.
  4. Establish which identity is used to authenticate.
  5. Inspect the relevant share and underlying file-system permissions.

SMB commonly uses TCP 445 for modern direct-hosted access. A successful network connection does not mean the requested folder operation is authorized.

Explain the home-network comparison

Two computers connected to one home router do not automatically publish every folder to one another. Sharing must be configured, the service must be reachable, and permissions must allow the request. This illustrates why “on the same network” and “authorized to read the files” are different conditions.

Use precise incident language

“The Z drive is broken” leaves the dependency unclear. “The mapped target resolves, but the server denies this account access to the share” narrows the investigation. Record the exact error and scope, including whether other users can access the same resource. Avoid changing broad permissions simply to make an unexplained failure disappear.

CLOSE THE NOTES. MAKE THE CONNECTION.

Recall check

Does assigning a user a mapped drive letter grant access to its files?

Reveal the reasoning

No. The mapping references a location. Network reachability, authentication, and the effective share and file permissions still govern access.
