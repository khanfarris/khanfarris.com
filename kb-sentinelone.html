NOTE 06 / Security operations

SentinelOne: detection to response_

Study basis: Concept study

THE PRINCIPLE

An endpoint alert becomes actionable when the process context and the response action are understood.

THE CONNECTION

A detection policy is more than a list of known bad files. The distinction between quarantining a file and isolating a host changes what containment actually achieves.

Read the activity behind the alert

Endpoint Detection and Response combines endpoint telemetry, detection, investigation, and response capabilities. In SentinelOne, related activity can be presented through Storyline context. A process tree helps an analyst ask which program launched the suspicious process, under which account, with which command line, and what happened next.

A browser launching a downloaded program and an approved management tool running a script may require different interpretations. A detection name alone does not establish intent. Check the process ancestry, file information, network activity, timing, and expected business use.

Detection is more than a database

Known indicators can identify recognized threats. Behavioral analysis can identify suspicious sequences even when a file has not previously been catalogued. Policy also determines how detections are handled. The presence of an agent does not prove that every detection triggers automatic remediation: policy, platform, configuration, and available capabilities matter.

Choose the action by its effect

  • Quarantine a file: restrict access to the identified file. This does not disconnect the entire endpoint.
  • Isolate a host: restrict its network communication to contain activity. Management connectivity may remain available according to the product and configuration.
  • Remediate: address malicious artifacts and changes within supported capabilities. Verify the outcome rather than assuming the button succeeded.

Rollback is a capability with prerequisites and platform limitations, not a replacement for recoverable backups. Containment decisions must consider active harm, confidence, asset importance, and the incident runbook.

Place EDR in the wider investigation

An endpoint process tree explains local execution. Identity logs, email evidence, and firewall events can explain parts of the incident that an endpoint alert does not show. Sysmon provides telemetry; deploying Sysmon alone does not create a complete EDR response platform. This note records conceptual tool study, not production SentinelOne administration.

CLOSE THE NOTES. MAKE THE CONNECTION.

Recall check

Does quarantining a suspicious executable isolate the workstation from the network?

Reveal the reasoning

No. File quarantine and host network isolation have different scopes. Confirm which action is required and verify its resulting state.
