NOTE 03 / Networking

VLSM address planning_

Study basis: Practiced calculations

THE PRINCIPLE

Size each subnet for its requirement, allocate on valid boundaries, and prevent overlaps inside the parent prefix.

THE CONNECTION

The department exercises became consistent when the largest block was placed first and each next allocation began after the previous broadcast.

From host requirements to prefixes

Variable Length Subnet Masking uses different prefix lengths within an address plan. For ordinary IPv4 broadcast subnets, choose the smallest host-bit count h satisfying 2^h − 2 ≥ required addresses. The prefix is 32 − h. A real design counts gateways and infrastructure as well as end devices and leaves suitable growth capacity.

For 100 warehouse devices, six host bits provide only 62 usable addresses. Seven provide 126, making /25 a candidate if the remaining capacity covers infrastructure and growth. For 50 engineering devices, /26 provides 62. Capacity calculations do not themselves configure a switch or enforce security policy.

Abbreviated addresses retain 10.60.24. The remaining 10.60.24.240/28 is unallocated. Usable ranges describe available host addresses, not a requirement to assign every address.

Why allocation order helps

Largest-first allocation is a reliable planning method, not a protocol requirement. It reduces the risk of leaving gaps too small or incorrectly aligned for larger subnets. A /26 must start on a 64-address boundary; an arbitrary unused host address is not a valid starting point.

A child subnet can begin at the same address as its parent. 10.60.24.0/24 describes 256 addresses; 10.60.24.0/25 describes the first 128. The prefix is part of the network identity. The parent represents the enclosing allocation, not an extra workstation network competing for those addresses.

Address plan versus implementation

A deployment needs Layer 3 interfaces or gateways, endpoint addressing, and routes. VLAN access and trunk configuration must carry the intended segments. Firewall or ACL policy controls communication between them. Correct arithmetic is necessary, but it does not establish that those controls exist.

Recall check

Are .224–.237 the usable addresses in 10.60.24.224/28?

Reveal the reasoning

No. .224 is the network, .239 is the broadcast, and .225–.238 are usable. This block has 16 total addresses and 14 ordinary usable addresses.
