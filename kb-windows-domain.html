NOTE 14 / Identity & access

Active Directory_

Concept Concept study

IN PLAIN ENGLISH

Active Directory Domain Services keeps a shared directory of users, computers, and groups. Domain controllers use it to support domain authentication and centralized administration.

Server, role, and domain controller

Windows Server is an operating system. Active Directory Domain Services (AD DS) is a role it can run. A server promoted to run AD DS as a domain controller maintains the directory and provides domain services. A file server can run Windows Server without being a domain controller.

A domain is a directory and administration boundary containing objects such as user accounts and computers. A group collects identities so permissions can be assigned together. An organizational unit (OU) is a container used to organize objects, delegate administration, and apply Group Policy. An OU is not a permission group.

Follow an ordinary domain sign-in

  1. A domain-joined PC has a relationship with the domain. It uses DNS to locate appropriate domain services.
  2. During a typical connected domain sign-in, Windows communicates with a domain controller to authenticate the user. Kerberos is commonly used.
  3. Kerberos provides tickets the user can use to request access to supported services without sending the password to every server.
  4. The destination service checks authorization, including group membership and its own permissions. A successful logon does not grant access to all files.

Windows can permit cached interactive sign-in when a domain controller is unavailable, depending on configuration and prior sign-ins. Reaching the desktop therefore does not prove the PC can currently contact a domain controller or obtain access to a network resource.

What Group Policy does

Administrators use Group Policy Objects (GPOs) to apply settings to users and computers, such as password-related configuration, firewall settings, or drive mappings. Where a GPO is linked, its filtering, inheritance, and processing determine who receives it. Changing a domain-wide GPO can affect many systems.

Troubleshoot from the symptom

SymptomUseful checks
One user cannot sign inExact error, correct domain, account enabled or locked, password status, and relevant log events.
Many devices cannot use domain servicesDNS configuration, domain controller reachability, service health, and recent changes.
Desktop sign-in works but a share failsNetwork path, current domain connectivity, user identity, group membership, and share/file permissions.
Expected policy is missingApplied-policy results, object location, links and filtering, and domain connectivity.

Keep AD DS and Entra ID distinct

Microsoft Entra ID, formerly Azure AD, is Microsoft’s cloud identity service. It is not simply an on-premises domain controller with a new name. Organizations can synchronize selected identities between AD DS and Entra ID, so a user may appear in both. Identify whether the problem concerns a local account, domain account, cloud sign-in, or synchronization before choosing a console or reset procedure.

PUT IT INTO WORDS

Check your understanding

Does every Windows Server machine validate domain logons?

Show an example answer

No. Windows Server can host many roles. Domain controllers running AD DS provide domain authentication services. A server used only for file sharing or an application is not automatically a domain controller.
