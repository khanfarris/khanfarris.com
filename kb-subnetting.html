NOTE 02 / Networking

Subnetting_

Concept Practiced calculations

IN PLAIN ENGLISH

Subnetting divides an IP address range into smaller networks. The subnet mask tells a device which addresses are local and which need a router.

What the slash means

In 192.168.204.30/28, the address identifies a device and /28 describes its network size. IPv4 has 32 bits: 28 identify the network and the remaining 4 distinguish addresses inside it. A bit is one binary digit, 0 or 1. An octet is a group of eight bits: eight bits can represent 256 values, numbered 0–255.

A subnet mask writes those network bits as ones and the host bits as zeros. The /28 mask is 11111111.11111111.11111111.11110000, or 255.255.255.240. For a destination on the same subnet, a host usually communicates directly. For another subnet, it normally sends the packet to its default gateway, a router interface.

Count the addresses

Host bits = 32 − prefix
Total addresses = 2host bits
Ordinary usable addresses = total − 2

For /28: 4 host bits give 16 total addresses. The first is the network address, the label for the whole subnet. The last is the broadcast address, used to address the subnet’s devices collectively. That leaves 14 ordinary host addresses. A gateway uses one of those 14; it is not a bonus address.

Work through 192.168.204.30/28

  1. Find the mask: 255.255.255.240.
  2. Find the increment in the changing octet: 256 − 240 = 16. Fourth-octet blocks start at 0, 16, 32, 48, and so on.
  3. 30 sits in the 16–31 block. Network: 192.168.204.16.
  4. The next block starts at .32, so broadcast is 192.168.204.31.
  5. Usable addresses: 192.168.204.17–192.168.204.30. The original address .30 is the last usable host.

Move the network boundary

Change the prefix or enter an address. Predict the network and broadcast before revealing the calculation.

When the boundary is in the third octet

For 10.50.132.75/21, 11 host bits give 2,048 total addresses. The mask is 255.255.248.0. Its third-octet increment is 256 − 248 = 8. The block containing 132 runs from 128 through 135.

ResultAddress
Network10.50.128.0
Broadcast10.50.135.255
Usable range10.50.128.1–10.50.135.254
Ordinary capacity2,046 host addresses

The increment is 8 in the third octet, while the entire subnet contains 2,048 addresses. These are different quantities. Calculate the broadcast from the network boundary, not by adding the increment to the original host address.

Use it at work

For a department with 50 devices, /26 provides 62 ordinary host addresses, leaving room for a gateway and some growth. Subnetting also helps diagnose a wrong mask, an incorrect gateway, or an overly broad firewall rule. An address plan still needs gateways, DHCP settings, and switch configuration to become a working network.

Two exceptions

The “minus two” rule describes ordinary IPv4 broadcast subnets. /31 point-to-point links can use both addresses; /32 identifies one address. Cloud platforms can reserve extra addresses.

PUT IT INTO WORDS

Check your understanding

Find the network, broadcast, mask, and ordinary usable capacity of 172.19.155.200/18.

Show an example answer

The mask is 255.255.192.0. The increment is 64 in the third octet, so 155 sits in 128–191. Network: 172.19.128.0. Broadcast: 172.19.191.255. Usable range: 172.19.128.1–172.19.191.254, giving 16,382 addresses.
