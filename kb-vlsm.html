NOTE 03 / Networking

VLSM_

Concept Practiced calculations

IN PLAIN ENGLISH

Variable Length Subnet Masking gives each subnet a size that fits its needs, instead of giving every department the same-sized block.

Why use different sizes?

Suppose a warehouse needs 100 device addresses but a kiosk network needs only 12. Giving both a /25 would reserve 128 addresses for each. VLSM lets the warehouse use /25 and the kiosks use /28. Both subnets can fit inside a larger allocation without overlapping. Read Subnetting first if network and broadcast addresses are still unfamiliar.

Choose a prefix from a requirement

Choose enough host bits that 2^h − 2 covers the required host addresses. Then calculate 32 − h for the prefix. For 100 devices, /26 gives only 62 usable addresses. /25 gives 126. Count the gateway, printers, management interfaces, and growth before finalizing a real plan.

Allocate the biggest blocks first

Use 10.60.24.0/24 as the parent allocation. Start with the largest requirement and place the next subnet after the previous subnet’s broadcast address. Each start must also be a valid boundary for its prefix.

Engineering10.60.24.128/26.129–.190.191

Kiosks10.60.24.224/28.225–.238.239

All shortened addresses keep the first three octets 10.60.24. The final block, 10.60.24.240/28, remains available. The first child can start at the same address as its parent: /24 describes the whole allocation, while /25 describes only its first half.

Catch the common mistakes

  • A /26 starts at a multiple of 64 in the fourth octet: .0, .64, .128, or .192. “The next free address” is not enough if it is misaligned.
  • The network and broadcast are not ordinary device addresses. In the kiosk subnet, .224 is the network, .239 is the broadcast, and .225–.238 are usable.
  • The prefix is part of the network definition. Write 10.60.24.128/26, not just “.128.”
  • Largest-first allocation is a practical method that avoids fragmentation. It is not a protocol requirement.

Turn the plan into a working office

Create the intended VLANs, assign their switch ports, and configure a router or Layer 3 switch interface for each subnet. Set up DHCP scopes with the matching mask, gateway, and DNS servers. Reserve or exclude statically assigned infrastructure addresses. Then apply rules for permitted traffic between departments and test both an allowed and a blocked connection. The calculation decides address capacity; these configuration steps implement it.

PUT IT INTO WORDS

Check your understanding

Why can’t 50 engineering devices use a /27, and what else should you count before choosing a /26?

Show an example answer

A /27 has only 30 ordinary usable addresses. A /26 has 62. Count the gateway, other infrastructure, and expected growth as well as the 50 devices. Ensure the chosen block starts on a valid boundary and does not overlap another subnet.
